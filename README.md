# Tarjetas digitales

Tarjetas de presentación digitales estáticas. Una carpeta por persona en `t/<slug>/`, servida por GitHub Pages.

Cada tarjeta es HTML autónomo: muestra los datos de contacto y permite descargar la vCard (`.vcf`). El código QR apunta a la URL de la tarjeta, no incrusta la vCard, de modo que los datos se pueden corregir después sin invalidar los QR que ya circulan.

Sin backend y sin dependencias externas más allá de las tipografías.
